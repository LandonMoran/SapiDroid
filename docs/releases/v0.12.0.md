# SapiDroid 0.12.0 — the neural voices

This is the first release since 0.11.0. It adds the three OneCore voices whose
sound is not synthesized from an acoustic model: **Eva** (American English),
**Sarah** (British English) and **Matilda** (Australian English), the Windows
"Cortana" voices. They join the existing **Download OneCore voices** list.

Everything else is unchanged: same engines, same output for every voice that
0.11.0 spoke, with no kernel or frontend work in this release.

Pick `app-arm64-v8a-release.apk` for virtually every current phone, or the
universal APK if you are unsure. Voice data is not included; install it from the
app. This build is signed with the same key as 0.11.0, so it installs over it and
keeps your downloaded voices.

## How these three voices work

A normal OneCore voice ships one acoustic model that turns phonemes into sound.
Eva, Sarah and Matilda do not: their `.APM` carries durations only, and the
spectrum, pitch, gain and voicing are predicted by a small neural network. The
network's layer stack is in a `.tdat` file, and an `.nnm` file describes its
inputs, output streams and weight precision (int8 or int16).

The engine now runs that network on the phone:

- `eva_voice.c` builds the network's 400+ linguistic features from the same
  `zf2` sentence tree the other voices use, runs it over the phone durations the
  APM produces, and hands the result to the existing float LSF vocoder — at the
  network's own order, 40 bands for Eva and Sarah and 24 for Matilda.
- `eva_nn.c` loads and evaluates the dense/LSTM "CMLP" stack; `eva_crf.c` runs
  Eva's `.br2`/`.ton`/`.acl` models, which replace the rule-based breaks,
  boundary tones and pitch accents with learned ones.
- `zb_synth` declines these voices (their APM has no acoustics to drive the HMM
  vocoder) and `zira_tts` routes them to the neural back end instead.

The neural code is MIT-licensed, taken from the engine Sapple vendors
(`Engine/onecore` in `Quinton1110/Sapple`, reconstructed from
`MSTTSEngine_OneCore.dll`), and its licence travels with the source in
`engine/LICENSE.neural`. The voice data itself is still Microsoft's and is not
in this repository or in the APK.

## Downloading them

The three appear at the end of the OneCore list with their languages. Picking
one downloads Sapple's bundle once (kept while the app is open, so trying
several voices costs one download) and installs the voice.

For these voices the installer copies **every** file the bundle has for that
voice, and treats the `.nnm`/`.tdat` pair as required rather than optional: the
match ignores case (Windows writes `M1033Eva.NNM` but `M2057Sarah.nnm`), falls
back to a search by voice name, and aborts with a message naming the missing
file instead of leaving a voice that loads and produces silence. The voice list
follows the same rule, so a neural voice appears in Android's engine list only
when both files are present.

Note that `.tdat` is by far the largest file a voice installs here, so expect
that download to take longer than David or Zira.

## Not verified

No voice audio was listened to for this release, on a device or otherwise. The
native code passes the host fast-path tests in CI and the APK builds and installs
(the same debug variant was built and handed over for testing before this tag),
but whether Eva, Sarah and Matilda actually sound right is exactly what this
release is meant to find out. The other voices' output is untouched by these
changes; their synthesis paths were not modified.
